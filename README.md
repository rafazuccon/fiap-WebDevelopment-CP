# Projeto de exercícios JavaScript — Console

10 exercícios introdutórios de JavaScript com resultados no console do navegador.

## Organização de pastas

```text
projeto-js-console/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── integrantes.txt
└── README.md
```

> Caso o professor tenha exigido uma estrutura de pastas específica em sala, ajuste os nomes de acordo com ela.

## Como testar no VS Code

1. Abra a pasta `projeto-js-console` no VS Code.
2. Abra `index.html` com **Live Server** (extensão opcional) ou diretamente no navegador.
3. Pressione **F12**, entre na aba **Console** e responda aos `prompt()`.
4. Observe as mensagens de saída de cada exercício, separadas por títulos.
5. Para testar outra vez, clique em **Executar os 10 exercícios novamente**.

## Exemplos de saída

- Exercício 1: `true`, `false`, `true`.
- Exercício 2: para 70 kg e 1,75 m, IMC `22.86` e `Peso ideal`.
- Exercício 3: contagem de 1 até 10.
- Exercício 4: imprime o array dos cinco heróis e cada nome.
- Exercício 5: idade 18 → `Permissão concedida`.
- Exercício 6: usuário `admin`, senha `1234` → `Login realizado com sucesso!`.
- Exercício 7: notas `[7, 8, 6, 7, 9, 5, 7]` → média `7.00`, aprovado.
- Exercício 8: nome `Ana` → `Olá dev Ana!`.
- Exercício 9: senha antiga `1234`, nova `5678` → senha alterada.
- Exercício 10: produto `150`, desconto `30` → final `120.00`.
