# Exercícios de JavaScript

Projeto com 10 exercícios básicos de JavaScript. Os resultados aparecem no console do navegador.

## Pastas

- `index.html`: página HTML
- `js/script.js`: os 10 exercícios
- `css/style.css`: estilo simples
- `integrantes.txt`: nomes, RMs e link do GitHub

## Para executar

1. Abra a pasta no VS Code.
2. Abra o arquivo `index.html` no navegador ou com Live Server.
3. Pressione F12 e entre em **Console**.
4. Responda às caixas de pergunta (prompt).
5. Veja os resultados. Para testar novamente, atualize a página.

## Git

Use `git log --oneline` para consultar os commits semânticos incluídos. Antes de enviar ao Teams, preencha `integrantes.txt`, coloque o projeto no seu repositório GitHub e confirme os 10 commits no GitHub.

A atividade também solicita um vídeo do projeto funcionando. O enunciado exige publicação no LinkedIn; caso não queira publicar, consulte o professor sobre uma forma alternativa de entrega.
